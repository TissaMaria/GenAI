 1. What is a Runnable?
A Runnable is a standard interface for components in LangChain.

It basically says:

“If you are a Runnable, you should be able to take an input and produce an output using invoke().”

runnable.invoke(input)
2. Why do we need Runnables?

Before Runnables, different components could have different methods:

Prompt → format()
LLM    → predict()
Parser → parse()

Because the methods were different, it was difficult to create a generic chain.

With Runnables:

Prompt → invoke()
LLM    → invoke()
Parser → invoke()

Now all components follow the same interface.

The | is essentially a convenient way to compose Runnables into a sequence.

What are Runnables in LangChain?

Runnables are a common interface used by LangChain components. They provide methods like invoke() so that different components such as prompts, LLMs, parsers, and retrievers can be used in a consistent way. Since they share the same interface, their outputs can be passed directly as inputs to the next component, allowing us to easily compose chains using operators like |.
